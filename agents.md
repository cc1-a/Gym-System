# Agent Rules and Memory

- **Mandatory Checks**: Before making code changes, the AI must read `guidelines.md`, `workflows.md`, `file_structure.md`, and `logs.md`.
- **Mandatory Updates**: After making changes, the AI must update the corresponding markdown files (especially `logs.md`).
- **Data Source**: Use local JSON (`data.json`) for data storage to allow easy local testing.
- **UI Design**: Keep designs dark mode, sleek, with neon green accents. It must look and feel like a mobile app (mobile-first layout).
